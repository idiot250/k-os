# k-OS

k-OS is a standalone digital sound instrument. the primary sound qualities i was looking for were experimental, a bit aggressive style edm, taking inspiration from tracks like luvcore dlux by MIDNIGHT CLUB. its intended sound palette combines distorted bass, harsh/resonant leads, noisy textures, and evolving rhythms. 

i built this because i wanted to find edm i liked for a long time, but while many were inspirational, i didn't find many that fit my very specific criteria. 

k-OS is designed around two operating modes, play and generate. play directly triggers notes and manipulates sound using physical controls, whilst generative produces rhythms with controls for changing params (tempo, sound energy, scales, effects, glitch etc).
